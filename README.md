# pi-clarify

Clarify your Pi editor draft before sending.

Press **Alt+G** to rewrite the current editor text. The clarified draft replaces the editor — press **Enter** to submit.

## Install

```bash
pi install npm:@rukaachan/pi-clarify
```

## Usage

* **Alt+G** — clarify editor draft (Esc/Ctrl+C to cancel)
* **/clarify** — pick clarify model and reasoning level

Config is saved at `~/.config/pi-clarify/config.json`.
